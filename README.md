# Laboratório de JavaScript

![JavaScript](https://img.shields.io/badge/JavaScript-B99000?style=flat-square&logo=javascript&logoColor=white) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css&logoColor=white)

Exercícios e experimentos para desenvolver lógica de programação, interatividade no navegador e jogos com Canvas.

## Explore os estudos

- [Fundamentos e primeiras interações](aula1/) — páginas e scripts introdutórios.
- [Funções](aula2/) — organização da lógica em funções.
- [Atividades](atividades/) — prática de JavaScript em páginas web.
- [Canvas](canvas/) — desenho, personagens, plataformas e lógica de jogo.
- [Parallax](parallax/) — experimento de efeito visual.

## Como visualizar

Abra o arquivo HTML do exercício escolhido no navegador. Para atividades que carregam arquivos JSON ou outros recursos, use um servidor local, como o Live Server do VS Code.

## Competências praticadas

Funções, eventos, manipulação de páginas, organização de scripts e desenho com Canvas. Este repositório reúne estudos; cada pasta é um exercício independente.
